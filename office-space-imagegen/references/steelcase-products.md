# Steelcase product matching guide

Use Steelcase-family furniture as the principal furniture in all generated office spaces. Fit the furniture family to the activity and the scale of the room. Do not put every product into every image and do not repeat an identical furniture package throughout a set.

## Useful official product families

| Office use | Steelcase product examples | Visual/product matching guidance |
|---|---|---|
| Open workstations / employee areas | Migration SE height-adjustable desks and benching; Answer workstation system; Universal Storage | Use desk groupings, appropriate privacy/screen elements, ergonomic work chairs, and low storage while preserving daylight and aisles. |
| Focused individual work | Migration SE or Ology desks; Leap, Gesture, Think, Series 1 or Series 2 task chairs; Universal Storage | Show an ergonomic task chair and usable desk relationship. Keep desktop accessories restrained. |
| Meeting rooms | Convene conference tables; appropriate Steelcase task/conference chairs; Universal Storage credenza | Choose table shape and seating count for room size; allow circulation and show sensible display/technology placement. |
| Collaboration / project rooms | media:scape; Steelcase Flex Single Table; ScapeSeries; Answer; mobile whiteboards where suited | Favor team interaction, content sharing, movable or reconfigurable setups. Avoid an unbroken generic desk row. |
| Lounges / informal conversation | Coalesse Ensemble Lounge System, Sidewalk Lounge, Coupe Lounge; complementary Coalesse/Steelcase tables | Build a fitting combination of modules, sofa, lounge chairs, ottomans, and occasional tables; vary open, face-to-face, and semi-private layouts. |
| Storage and support | Universal Storage (shelves, bookcases, cabinets, pedestals); Answer freestanding storage | Use as a functional support or zoning piece, never as arbitrary clutter. |

Coalesse is a Steelcase brand focused on social/ancillary spaces. Product ranges, materials, dimensions, and regional availability can change. This guide is for image planning, not a bill of materials.

## Product verification and image claims

When the user names an exact product/model, or asks for product-accurate imagery, verify the current appearance and category using Steelcase’s official product page or official product imagery. Use this as the starting point for the image reference when the generation tool supports reference images. If the exact model cannot be confirmed, use a suitable verified family or describe a category-level product without asserting an exact SKU.

Generated interiors should show furniture naturally used in context, not isolated as a product showroom. A generated image can evoke a Steelcase product family but should not be described as an exact catalog render, exact colorway, exact specification, or purchasable configuration unless each detail was actually verified.
